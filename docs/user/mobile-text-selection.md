# Selecting text on iPhone and iPad

Press and hold text to begin selecting, then drag the selection handles to extend the
highlight. In chat and rendered Markdown files, a quote's paragraphs share one selection,
so you can copy a multi-paragraph quote without copying each paragraph separately.
Code blocks, tables, and images remain separate from adjacent prose.

The file source view supports selection across lines, including Select All and Copy with
a hardware keyboard. Copying source preserves tabs and blank lines and excludes line numbers.
Syntax highlighting can finish without clearing your selection.

Source and rendered Markdown previews have extra scrolling room below the last line. Scroll
the end of the file upward to reach the selection handles above the bottom of the screen.
