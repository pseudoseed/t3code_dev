# Terminals on mobile

Every thread can run several shells in its workspace. Open one from the thread toolbar, the
terminal menu, or a project script.

## On a phone

The terminal opens as its own screen. The terminal menu in the header switches between the
thread's shells, opens another one, and changes the text size. Use the back button to return to
the chat.

## With a hardware keyboard

Line editing works the way it does on a Mac. **Option+Left** and **Option+Right** move by word,
**Option+Delete** deletes the word behind the cursor, and **Command+Left**, **Command+Right** and
**Command+Delete** jump to or clear back to the start of the line. Arrows, Escape, Tab, Home, End
and the page keys reach the shell as themselves, so command history and full-screen programs
behave normally.

## Selecting and copying

Press and hold on the terminal, then drag to highlight text. Letting go copies the highlight to
the clipboard. **Command+C** copies the current highlight and **Command+V** pastes.

## On a tablet

The terminal opens beside the chat instead of covering it. A tab strip across the top of the pane
lists the thread's shells: tap one to switch, **+** to start another, and **x** on a tab to end
that shell. Ending the last one closes the pane.

Drag the divider between the chat and the pane to resize it. The pane keeps that size for the rest
of the session.

The pane header also has:

- **Dock terminal below** to move the pane under the chat, and **Dock terminal to the right** to
  put it back. The choice is remembered on the device. Docking below needs a window tall enough to
  leave the chat usable, so the control is hidden in short windows.
- **Open terminal full screen** to move the terminal to its own screen. The pane closes; reopen it
  from the thread toolbar.
- **Close terminal pane** to hide the terminals without ending them. Shells keep running, and the
  tab strip shows them again next time you open the pane.

Files and git can use the trailing pane at the same time as a bottom-docked terminal.
