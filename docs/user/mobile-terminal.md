# Terminals on mobile

Every thread can run several shells in its workspace. Open one from the thread toolbar, the
terminal menu, or a project script.

On phones, the terminal opens as its own screen. The terminal menu in the header switches
between the thread’s shells, opens another one, and changes the text size. Use the back button
to return to the chat.

On iPad, open the terminal beside chat or dock it below. Use the tabs to switch shells and the
plus button to create another. You can expand a terminal to full screen. Closing the pane keeps
its shells running; closing a tab ends that shell. Shells are shared with desktop when both
clients connect to the same environment and thread.

On iOS, long-press and drag to select terminal text, or use Select All. Copy sends the selection
to the clipboard. Add to chat lets you choose captured lines and attach them to your next
message.

Use the terminal’s keyboard controls to send special keys or paste clipboard text. With a hardware
keyboard on iOS, arrows, Escape, Tab, and Control shortcuts are sent to the shell.
